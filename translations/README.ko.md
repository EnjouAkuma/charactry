## Charactry란?

Charactry는 오리지널 캐릭터(OC) 제작자를 위한 전용 공간입니다. 캐릭터를 메모 앱, Google Docs, 수십 개의 폴더에 흩어 두는 대신, **프로필, 일러스트, 유니버스, 관계, 설정, 스토리**를 한곳에 정리하세요. 그냥 보관하는 데 그치지 않고, 보기에도 좋게 만들어졌습니다.

**로컬 우선**입니다. 캐릭터는 다른 사람의 서버가 아니라 내 기기에 저장됩니다. 사용하는 데 계정이 필요하지 않습니다.

사용 방법은 두 가지이며, 인터페이스와 라이선스는 동일하게 공유됩니다.

| | **Windows 앱** | **웹 버전** |
|---|---|---|
| 사용 방법 | 다운로드 후 설치(.exe) | 링크만 열면 끝, 설치 불필요 |
| 기기 | Windows | 스마트폰, 태블릿, 컴퓨터: Mac, Linux, iOS, Android도 가능 |
| 내 데이터 | 내 컴퓨터에 저장 | 내 기기의 브라우저에 저장 |
| 오프라인 | 가능(완전 오프라인) | 데이터는 기기에 저장, 홈 화면에 추가 가능 |
| 플러그인 | 폴더에 넣기 | `.zip` 또는 `.rar`에서 바로 설치 |

> **웹 버전:** <https://enjouakuma.github.io/charactry/>

## ✨ 기능(무료)

핵심 앱은 완전 무료이며, 기본 기능에 유료 장벽이 없습니다.

### 캐릭터
- **풍부한 캐릭터 프로필**: 이름, 별명, 대명사, 나이, 키, 종족, 성향, 외모, 특성, 호불호, 강점과 약점, 배경 이야기, 능력, 잡학, 명대사 등.
- **아바타와 배너**(자르기 도구 내장), 캐릭터별 이미지 갤러리, 그리고 세계관에 필요한 것을 마음대로 추가하는 **사용자 지정 탭/필드**(능력, 학교 기록, 테마곡 등).
- **희귀도 시스템**: OC를 일반, 희귀, 영웅, 전설, 신화로 분류하고 각각 고유한 애니메이션 테두리와 파티클 효과를 적용합니다. 빛날 자격이 있는 캐릭터도 있으니까요.
- **폴더와 하위 폴더**, **즐겨찾기**, **태그**, 전체 캐릭터를 대상으로 하는 즉시 **검색**.
- 캐릭터 **복제**, 개별 캐릭터 **내보내기/가져오기**, 다운로드 가능한 **캐릭터 시트**.

### 유니버스와 AU
- **여러 유니버스와 평행 AU**에 걸쳐 캐릭터를 정리하고, 각각 고유한 색상, 설명, 연표, (선택) 테마를 지정할 수 있습니다.
- **유니버스별 변형**: 같은 OC를 다른 설정으로 재해석하고, 데이터와 일러스트도 따로 관리합니다.
- 상단 바에서 클릭 한 번으로 세계를 전환합니다.

### 관계
- 누가 누구를 아는지 그려 보세요: 가족, 친구, 연인, 라이벌, 적, 스승 등 100가지가 넘는 기본 관계 유형, 또는 직접 입력.
- 관계 유형을 색상으로 구분하고, 캐릭터 프로필에서 모든 연결을 확인할 수 있습니다.

### 세계관 구축
- **세계, 장소, 세력, 종족, 마법 체계, 연표**를 모두 캐릭터와 연결할 수 있습니다.
- **로어북**: 키워드에 반응하는 세계 지식을 한 번 쓰고 계속 재사용하세요.
- 분류와 고정 기능이 있는 **로어 노트**, 그리고 챕터, Markdown, 실시간 미리보기, `@캐릭터` 멘션을 지원하는 **스토리** 편집기.

### 창작 도구
- 영감이 낮잠을 잘 때는 **OC 생성기**와 **AU 생성기**.
- **랜덤 뽑기**, **글쓰기 프롬프트**, **활동 기록**, 키보드 단축키가 있는 **명령 팔레트**.

### 나만의 스타일로
- 여러 기본 테마, 사용자 지정 강조색과 그라데이션, 세밀한 UI 색상 재정의.
- **16개 언어**: English, 日本語, Español (España), Español (México), Français, Deutsch, Italiano, 한국어, Português (BR), Português (PT), Русский, 中文（简体）, 中文（繁體）, 粵語, Filipino, Tiếng Việt.

## 🌐 웹 버전 사용하기

- **데이터는 내 곁에.** 모든 것이 내 기기의 브라우저에 저장됩니다. 탭을 닫고 내일 돌아와도 그대로 있습니다. 서버에는 아무것도 업로드되지 않습니다.
- **백업하세요.** 브라우저의 사이트 데이터를 지우거나 비공개 창을 사용하면 데이터가 삭제되므로, **설정 → 전체 백업 다운로드**를 가끔 사용하고 다른 기기로 옮길 때도 사용하세요.
- **앱처럼 설치.** 스마트폰이나 태블릿에서는 브라우저의 "홈 화면에 추가"를 사용하세요.
- **웹 버전의 AI 스튜디오(PLUS):** **AI 스튜디오 → 설정**에서 본인의 [OpenRouter](https://openrouter.ai) 계정(무료 모델 제공), OpenAI 호환 엔드포인트, 또는 로컬 Ollama를 연결하세요. 키는 브라우저에만 저장됩니다.
- **플러그인:** 기본 제공되는 8개 플러그인이 포함되어 있습니다. 더 추가하려면 **설정 → 플러그인 설치**에서 `.zip` 또는 `.rar` 파일을 선택하세요.
