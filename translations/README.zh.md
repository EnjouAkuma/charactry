## Charactry 是什么？

Charactry 是专为原创角色（OC）创作者打造的空间。无需再把角色分散在笔记应用、Google Docs 和一堆文件夹里，你可以在一个整洁的地方管理**档案、画作、宇宙、关系、设定和故事**——而且设计得赏心悦目，而不只是把东西归档。

它是**本地优先**的：你的角色保存在你自己的设备上，而不是别人的服务器上。使用无需账户。

两种使用方式，界面相同，许可证共用：

| | **Windows 应用** | **网页版** |
|---|---|---|
| 在哪里用 | 下载并安装（.exe） | 打开链接即可，无需安装 |
| 设备 | Windows | 手机、平板或电脑：Mac、Linux、iOS、Android 均可 |
| 你的数据 | 保存在你的电脑上 | 保存在你设备上的浏览器中 |
| 离线 | 支持，完全离线 | 数据保存在你的设备上；可添加到主屏幕 |
| 插件 | 放入文件夹 | 直接通过 `.zip` 或 `.rar` 安装 |

> **网页版：** <https://enjouakuma.github.io/charactry/>

## ✨ 功能（免费）

核心应用完全免费，基础功能没有付费墙。

### 角色
- **完整的角色档案**：名称、昵称、代词、年龄、身高、种族、阵营、外貌、特质、喜好与厌恶、优缺点、背景故事、能力、小知识、语录等。
- **头像与横幅**（内置裁剪工具）、每个角色的图库，以及**自定义标签页／字段**，你的世界需要什么就加什么（能力、学校记录、主题曲，随意）。
- **稀有度系统**：将 OC 标记为普通、稀有、史诗、传说或神话，每个等级都有专属的动态边框和粒子特效。因为有些角色就是值得发光。
- **文件夹与子文件夹**、**收藏**、**标签**，以及对整个角色阵容的即时**搜索**。
- **复制**角色、**导出／导入**单个角色，以及可下载的**角色设定表**。

### 宇宙与 AU
- 在**多个宇宙和平行 AU** 之间整理角色，每个都有自己的颜色、描述、时间线和（可选的）主题。
- **每个宇宙的版本**：同一个 OC 在不同设定下重新演绎，各自拥有独立的数据和画作。
- 在顶部栏一键切换世界。

### 关系
- 描绘谁认识谁：家人、朋友、恋人、对手、敌人、导师，以及 100 多种内置关系类型，也可以自己输入。
- 为关系类型设置颜色，并在角色档案中查看每一段联系。

### 世界观构建
- **世界、地点、势力、种族、魔法体系和时间线**，全部可以关联到你的角色。
- **设定集**：按关键字匹配的世界知识，写一次即可反复使用。
- 支持分类和置顶的**设定笔记**，以及支持章节、Markdown、实时预览和 `@角色` 提及的**故事**编辑器。

### 创作工具
- 灵感打盹的时候，有 **OC 生成器**和 **AU 生成器**。
- **随机器**、**写作灵感**、**活动追踪**，以及带键盘快捷键的**命令面板**。

### 由你定制
- 多种基础主题、自定义强调色和渐变，以及精细的界面颜色覆盖。
- **10 种语言**：English、日本語、한국어、中文、粵語、Español、Français、Português (BR)、Русский、Deutsch。

### 免费插件（已包含）
| 插件 | 功能 |
|---|---|
| **年龄计算器** | 在现实与自定义历法之间追踪年龄，保持连贯性 |
| **智能标签** | 在整个角色阵容中分类、换色、重命名、合并和清理标签 |
| **模板** | 将档案布局保存为可复用的模板，快速创建新角色 |
| **名称生成器** | 20 多种文化风格、类型筛选、姓氏开关和名称历史 |

## 🌐 使用网页版

- **数据始终由你掌控。**一切都保存在你设备上的浏览器中。关闭标签页，明天再回来，一切都还在。不会向任何服务器上传内容。
- **记得备份。**清除浏览器的网站数据（或使用隐私窗口）会将其删除，因此请不时使用**设置 → 下载完整备份**，更换设备时也需要使用。
- **像应用一样安装。**在手机或平板上，使用浏览器的“添加到主屏幕”。
- **网页版的 AI 工作室（PLUS）：**在 **AI 工作室 → 设置**中连接你自己的 [OpenRouter](https://openrouter.ai) 账户（提供免费模型）、任何 OpenAI 兼容端点或本地 Ollama。你的密钥只保存在浏览器中。
- **插件：**内置的八个插件已包含在内。想添加更多，请使用**设置 → 安装插件**，选择 `.zip` 或 `.rar` 文件。
