## Charactry 係乜嘢？

Charactry 係專為原創角色（OC）創作者而設嘅空間。你唔使再將角色散落喺筆記應用程式、Google Docs 同十幾個資料夾入面，而係有一個整齊嘅地方放**檔案、畫作、宇宙、關係、設定同故事**——而且做得好睇，唔係淨係將嘢歸檔咁簡單。

佢係**本機優先**：你嘅角色留喺你自己嘅裝置，唔係放喺別人部伺服器。使用唔使註冊帳戶。

有兩種用法，介面一樣，授權亦都共用：

| | **Windows 應用程式** | **網頁版** |
|---|---|---|
| 邊度用 | 下載並安裝（.exe） | 直接開連結，唔使安裝 |
| 裝置 | Windows | 手機、平板或電腦：Mac、Linux、iOS、Android 都得 |
| 你嘅資料 | 儲存喺你部電腦 | 儲存喺你裝置上嘅瀏覽器 |
| 離線 | 可以，完全離線 | 資料留喺你裝置；可以加去主畫面 |
| 外掛 | 放入資料夾 | 直接由 `.zip` 或者 `.rar` 安裝 |

> **網頁版：** <https://enjouakuma.github.io/charactry/>

## ✨ 功能（免費）

核心應用程式完全免費，基本功能唔設付費牆。

### 角色
- **完整角色檔案**：名稱、暱稱、代詞、年齡、身高、種族、陣營、外貌、特質、喜惡、強弱項、背景故事、能力、小知識、語錄等等。
- **頭像同橫幅**（內置裁剪工具）、每個角色都有圖片庫，仲有**自訂分頁／欄位**，你個世界需要乜就加乜（力量、學校紀錄、主題曲，乜都得）。
- **稀有度系統**：將 OC 標記為普通、稀有、史詩、傳說或者神話，每個等級都有自己嘅動態邊框同粒子特效。因為有啲角色就係值得發光。
- **資料夾同子資料夾**、**最愛**、**標籤**，仲有即時**搜尋**成個角色陣容。
- **複製**角色、**匯出／匯入**單一角色，同可以下載嘅**角色設定表**。

### 宇宙同 AU
- 喺**多個宇宙同平行 AU** 之間整理角色，每個都有自己嘅顏色、描述、時間線同（可選）主題。
- **每個宇宙嘅版本**：同一個 OC，喺唔同場景重新演繹，各自擁有獨立嘅資料同畫作。
- 喺頂部列一撳就可以切換世界。

### 關係
- 畫出邊個識邊個：家人、朋友、戀人、對手、敵人、導師，以及 100 多種內置關係類型，或者自己輸入。
- 用顏色分類關係類型，喺角色檔案睇到每一段連繫。

### 世界觀設定
- **世界、地點、勢力、種族、魔法體系同時間線**，全部都可以連結到你嘅角色。
- **設定集**：按關鍵字配對嘅世界知識，寫一次就可以重複使用。
- 有分類同置頂功能嘅**設定筆記**，同支援章節、Markdown、即時預覽同 `@角色` 提及嘅**故事**編輯器。

### 創作工具

- **隨機器**、**寫作靈感**、**活動追蹤**，仲有帶鍵盤快捷鍵嘅**指令面板**。

### 由你話事
- 多個基本主題、自訂強調色同漸變，以及細緻嘅介面顏色覆寫。
- **16 種語言**：English、日本語、Español (España)、Español (México)、Français、Deutsch、Italiano、한국어、Português (BR)、Português (PT)、Русский、中文（简体）、中文（繁體）、粵語、Filipino、Tiếng Việt。

## 🌐 使用網頁版

- **你嘅資料留喺你身邊。**所有嘢都儲存喺你裝置上嘅瀏覽器。關閉分頁，聽日再返嚟，仍然喺度。冇任何嘢會上傳去伺服器。
- **記得備份。**清除瀏覽器嘅網站資料（或者用私人視窗）會令資料消失，所以請不時用**設定 → 下載完整備份**，換裝置嘅時候亦都要用。
- **可以好似應用程式咁安裝。**喺手機或者平板，用瀏覽器嘅「加去主畫面」。
- **網頁版嘅 AI 工作室（PLUS）：**喺 **AI 工作室 → 設定**連接你自己嘅 [OpenRouter](https://openrouter.ai) 帳戶（有免費模型）、任何 OpenAI 相容端點，或者本機 Ollama。你嘅金鑰只會留喺你嘅瀏覽器。
- **外掛：**八個內置外掛已經包括。想加多啲，用**設定 → 安裝外掛**，然後揀 `.zip` 或者 `.rar` 檔案。
