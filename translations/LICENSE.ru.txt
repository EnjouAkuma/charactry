1. Общие сведения

Charactry — это персональное приложение для управления персонажами и построения миров, созданное и поддерживаемое Yuuma Akira.

Устанавливая или используя Charactry, вы соглашаетесь со следующими Условиями использования. Если вы не согласны, не устанавливайте и не используйте программное обеспечение.

Эти условия распространяются на:

Charactry (стандартная версия)

Charactry PLUS

2. Лицензия на использование программного обеспечения

Charactry предоставляется по лицензии, а не продаётся.

Вам предоставляется личная, непередаваемая, неисключительная лицензия на использование Charactry в личной или профессиональной творческой работе.

Вы можете:

• Использовать программное обеспечение для личных проектов
• Использовать программное обеспечение для коммерческих творческих проектов (книги, игры и т. д.)
• Создавать плагины или расширения для Charactry
• Делиться созданными вами плагинами

Вы НЕ можете:

• Распространять установщик Charactry или его изменённые версии
• Переупаковывать или зеркалировать программное обеспечение для загрузки в других местах
• Выполнять обратную разработку или извлекать исходный код для дальнейшего распространения
• Выдавать Charactry за собственное программное обеспечение

Официальные загрузки должны осуществляться из официальных источников распространения, предоставленных разработчиком.

3. Ограничения на распространение

Строго запрещается:

• Распространять файлы приложения Charactry
• Распространять установщик
• Загружать программное обеспечение на сторонние зеркала для скачивания
• Продавать копии Charactry

Если вы хотите поделиться программным обеспечением с другими, вместо этого вы должны дать ссылку на официальный источник загрузки.

4. Charactry PLUS

Charactry PLUS — это премиальная версия программного обеспечения.

Charactry PLUS может включать:

• дополнительные функции
• расширенные инструменты
• экспериментальные системы
• расширенные возможности ИИ

Несанкционированная разблокировка, взлом или обход систем лицензирования Charactry PLUS запрещены.

Распространение изменённых сборок, разблокирующих функции PLUS, строго запрещено.

5. Плагины и расширения

Charactry поддерживает плагины, созданные пользователями.

Пользователи могут:

• Создавать плагины
• Свободно делиться плагинами
• Распространять плагины самостоятельно

Однако:

• Плагины не должны содержать исходный код Charactry или файлы приложения
• Плагины не должны выдавать себя за официальное программное обеспечение Charactry
• Плагины не должны изменять системы лицензирования

6. Ограничения на коммерческие плагины

Плагины, созданные для Charactry, не могут продаваться с целью получения прибыли без явного разрешения разработчика.

Разрешено:

• Бесплатные плагины
• Плагины, поддерживаемые пожертвованиями
• Плагины с открытым исходным кодом

Не разрешено:

• Платные плагины
• Маркетплейсы плагинов, взимающие плату за загрузку
• Монетизируемые наборы плагинов

Эта политика призвана сохранить экосистему Charactry доступной для всех пользователей.
