## Charactry とは？

Charactry は、オリジナルキャラクター（OC）を作る人のための専用スペースです。キャラクターをメモアプリや Google ドキュメント、たくさんのフォルダに散らばらせる代わりに、**プロフィール、イラスト、ユニバース、関係、設定、ストーリー**を一か所にまとめられます。しまっておくだけでなく、眺めて楽しいデザインです。

**ローカル優先**なので、キャラクターのデータは他人のサーバーではなくあなたのデバイスに保存されます。利用にアカウントは不要です。

使い方は 2 通り。どちらも同じインターフェースで、ライセンスも共通です。

| | **Windows アプリ** | **Web 版** |
|---|---|---|
| 利用方法 | ダウンロードしてインストール（.exe） | リンクを開くだけ、インストール不要 |
| デバイス | Windows | スマートフォン、タブレット、パソコン（Mac、Linux、iOS、Android も可） |
| データの保存先 | お使いのパソコン | お使いの端末のブラウザ内 |
| オフライン | 可能（完全オフライン） | データは端末内に保存。ホーム画面に追加可能 |
| プラグイン | フォルダに入れる | `.zip` や `.rar` から直接インストール |

> **Web 版：** <https://enjouakuma.github.io/charactry/>

## ✨ 機能（無料）

基本アプリは完全無料です。基本機能に課金の壁はありません。

### キャラクター
- **充実したキャラクタープロフィール**：名前、ニックネーム、代名詞、年齢、身長、種族、属性、外見、特徴、好き嫌い、長所短所、背景、能力、豆知識、名言など。
- **アバターとバナー**（クロップ機能付き）、キャラクターごとの画像ギャラリー、そして**カスタムタブ／フィールド**で世界観に必要なものを自由に追加（能力、学校記録、テーマ曲など）。
- **レアリティシステム**：OC をコモン、レア、エピック、レジェンダリー、ミシックに分類。それぞれ専用のアニメーション枠とパーティクル演出付き。輝く価値のあるキャラクターはいるものです。
- **フォルダとサブフォルダ**、**お気に入り**、**タグ**、キャラクター全員を対象にした即時**検索**。
- キャラクターの**複製**、単体の**エクスポート／インポート**、ダウンロードできる**キャラクターシート**。

### ユニバースと AU
- **複数のユニバースやパラレル AU** にまたがってキャラクターを整理。それぞれに色、説明、年表、（任意で）テーマを設定できます。
- **ユニバースごとのバリアント**：同じ OC を別の設定で描き直し、データやイラストも別々に管理。
- 上部バーからワンクリックで世界を切り替え。

### 関係
- 誰が誰を知っているのかを可視化：家族、友人、恋人、ライバル、敵、師匠など 100 種類以上の関係タイプ、または自由入力。
- 関係タイプを色分けし、キャラクターのプロフィールですべてのつながりを確認できます。

### 世界観づくり
- **世界、場所、勢力、種族、魔法体系、年表**をすべてキャラクターと関連付けられます。
- **ロアブック**：キーワードに反応する世界知識を、一度書けば何度でも活用できます。
- カテゴリやピン留めに対応した**ロアノート**と、章、Markdown、ライブプレビュー、`@キャラクター` メンションに対応した**ストーリー**エディタ。

### 創作ツール
- ひらめきがお昼寝中のときは **OC ジェネレーター**と **AU ジェネレーター**。
- **ランダマイザー**、**ライティングプロンプト**、**アクティビティ記録**、キーボードショートカット付きの**コマンドパレット**。

### 自分好みに
- 複数のベーステーマ、カスタムアクセントカラーとグラデーション、細かな UI カラーの上書き。
- **10 言語対応**：English、日本語、한국어、中文、粵語、Español、Français、Português (BR)、Русский、Deutsch。

### 無料プラグイン（同梱）
| プラグイン | できること |
|---|---|
| **年齢計算機** | 現実の暦や独自の暦で年齢を管理し、設定の整合性を保つ |
| **スマートタグ** | 全キャラクターのタグを分類、色分け、名前変更、統合、整理 |
| **テンプレート** | プロフィールのレイアウトをテンプレートとして保存し、新キャラクターに再利用 |
| **名前ジェネレーター** | 20 以上の文化スタイル、ジャンル絞り込み、姓の切り替え、履歴 |

## 🌐 Web 版の使い方

- **データはあなたの手元に。**すべてお使いの端末のブラウザ内に保存されます。タブを閉じても、明日戻ってきても、そのまま残っています。サーバーには何もアップロードされません。
- **バックアップをお忘れなく。**ブラウザのサイトデータを消去したり、プライベートウィンドウを使ったりすると消えてしまいます。**設定 → フルバックアップをダウンロード**を時々行い、別の端末へ移るときにも使ってください。
- **アプリのようにインストール。**スマートフォンやタブレットでは、ブラウザの「ホーム画面に追加」を使います。
- **Web 版の AI スタジオ（PLUS）：** **AI スタジオ → セットアップ**で、ご自身の [OpenRouter](https://openrouter.ai) アカウント（無料モデルあり）、OpenAI 互換エンドポイント、またはローカルの Ollama を接続します。キーはブラウザ内にのみ保存されます。
- **プラグイン：**内蔵の 8 つのプラグインが含まれています。追加するには**設定 → プラグインをインストール**で `.zip` または `.rar` ファイルを選びます。
