1. Descripción general

Charactry es una aplicación personal de gestión de personajes y creación de mundos, creada y mantenida por Yuuma Akira.

Al instalar o usar Charactry, aceptas los siguientes Términos de servicio. Si no estás de acuerdo, no instales ni uses el software.

Estos términos se aplican a:

Charactry (Edición estándar)

Charactry PLUS

Puedes:

• Usar el software para proyectos personales
• Usar el software para proyectos creativos comerciales (libros, juegos, etc.)
• Crear plugins o extensiones para Charactry
• Compartir los plugins que crees

NO puedes:

• Redistribuir el instalador de Charactry ni versiones modificadas del mismo
• Reempaquetar o replicar el software para su descarga en otros sitios

Las descargas oficiales deben proceder de las fuentes de distribución oficiales facilitadas por el desarrollador.

3. Restricciones de redistribución

Queda estrictamente prohibido lo siguiente:

• Redistribuir los archivos de la aplicación Charactry
• Redistribuir el instalador
• Subir el software a sitios espejo de descargas de terceros
• Vender copias de Charactry

Si quieres compartir el software con otras personas, debes enlazar a la fuente de descarga oficial.

Charactry PLUS es una edición premium del software.

Charactry PLUS puede incluir:

• funciones adicionales

• sistemas experimentales
• capacidades de IA ampliadas

Está prohibido desbloquear, crackear o eludir sin autorización los sistemas de licencia de Charactry PLUS.

5. Plugins y extensiones

Charactry admite plugins creados por los usuarios.

Los usuarios pueden:

• Crear plugins
• Compartir plugins libremente
• Distribuir plugins de forma independiente

Sin embargo:

• Los plugins no deben incluir código fuente ni archivos de la aplicación Charactry
• Los plugins no deben hacerse pasar por software oficial de Charactry
• Los plugins no deben modificar los sistemas de licencia

6. Restricciones sobre plugins comerciales

Los plugins creados para Charactry no pueden venderse con ánimo de lucro salvo que el desarrollador conceda un permiso expreso.

Permitido:

• Plugins gratuitos
• Plugins sostenidos por donaciones
• Plugins de código abierto

No permitido:

• Plugins de pago
• Mercados de plugins que cobren por las descargas
• Paquetes de plugins monetizados

Esta política existe para mantener el ecosistema de Charactry accesible para todos los usuarios.
