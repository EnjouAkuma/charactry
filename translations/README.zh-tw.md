## Charactry 是什麼？

Charactry 是專為原創角色（OC）創作者打造的空間。無需再把角色分散在筆記應用、Google Docs 和一堆資料夾裡，你可以在一個整潔的地方管理**檔案、畫作、宇宙、關係、設定和故事**——而且設計得賞心悅目，而不只是把東西歸檔。

它是**本地優先**的：你的角色儲存在你自己的裝置上，而不是別人的伺服器上。使用無需帳號。

兩種使用方式，介面相同，授權共用：

| | **Windows 應用** | **網頁版** |
|---|---|---|
| 在哪裡用 | 下載並安裝（.exe） | 開啟連結即可，無需安裝 |
| 裝置 | Windows | 手機、平板或電腦：Mac、Linux、iOS、Android 均可 |
| 你的資料 | 儲存在你的電腦上 | 儲存在你裝置上的瀏覽器中 |
| 離線 | 支援，完全離線 | 資料儲存在你的裝置上；可新增到主螢幕 |
| 外掛 | 放入資料夾 | 直接通過 `.zip` 或 `.rar` 安裝 |

> **網頁版：** <https://enjouakuma.github.io/charactry/>

## ✨ 功能（免費）

核心應用完全免費，基礎功能沒有付費牆。

### 角色
- **完整的角色檔案**：名稱、暱稱、代詞、年齡、身高、種族、陣營、外貌、特質、喜好與厭惡、優缺點、背景故事、能力、小知識、語錄等。
- **頭像與橫幅**（內建裁剪工具）、每個角色的相簿，以及**自訂標籤頁／欄位**，你的世界需要什麼就加什麼（能力、學校紀錄、主題曲，隨意）。
- **稀有度系統**：將 OC 標記為普通、稀有、史詩、傳說或神話，每個等級都有專屬的動態邊框和粒子特效。因為有些角色就是值得發光。
- **資料夾與子資料夾**、**收藏**、**標籤**，以及對整個角色陣容的即時**搜尋**。
- **複製**角色、**匯出／匯入**單個角色，以及可下載的**角色設定表**。

### 宇宙與 AU
- 在**多個宇宙和平行 AU** 之間整理角色，每個都有自己的顏色、描述、時間線和（可選的）主題。
- **每個宇宙的版本**：同一個 OC 在不同設定下重新演繹，各自擁有獨立的資料和畫作。
- 在頂部欄一鍵切換世界。

### 關係
- 描繪誰認識誰：家人、朋友、戀人、對手、敵人、導師，以及 100 多種內建關係型別，也可以自己輸入。
- 為關係型別設定顏色，並在角色檔案中檢視每一段聯絡。

### 世界觀構建
- **世界、地點、勢力、種族、魔法體系和時間線**，全部可以關聯到你的角色。
- **設定集**：按關鍵字匹配的世界知識，寫一次即可反覆使用。
- 支援分類和置頂的**設定筆記**，以及支援章節、Markdown、即時預覽和 `@角色` 提及的**故事**編輯器。

### 創作工具
- 靈感打盹的時候，有 **OC 生成器**和 **AU 生成器**。
- **隨機器**、**寫作靈感**、**活動追蹤**，以及帶鍵盤快捷鍵的**命令面板**。

### 由你定製
- 多種基礎主題、自訂強調色和漸變，以及精細的介面顏色覆蓋。
- **16 種語言**：English、日本語、Español (España)、Español (México)、Français、Deutsch、Italiano、한국어、Português (BR)、Português (PT)、Русский、中文（简体）、中文（繁體）、粵語、Filipino、Tiếng Việt。

## 🌐 使用網頁版

- **資料始終由你掌控。**一切都儲存在你裝置上的瀏覽器中。關閉標籤頁，明天再回來，一切都還在。不會向任何伺服器上傳內容。
- **記得備份。**清除瀏覽器的網站資料（或使用隱私視窗）會將其刪除，因此請不時使用**設定 → 下載完整備份**，更換裝置時也需要使用。
- **像應用一樣安裝。**在手機或平板上，使用瀏覽器的“新增到主螢幕”。
- **網頁版的 AI 工作室（PLUS）：**在 **AI 工作室 → 設定**中連線你自己的 [OpenRouter](https://openrouter.ai) 帳號（提供免費模型）、任何 OpenAI 相容端點或本地 Ollama。你的金鑰只儲存在瀏覽器中。
- **外掛：**內建的八個外掛已包含在內。想新增更多，請使用**設定 → 安裝外掛**，選擇 `.zip` 或 `.rar` 檔案。
